# ADR-007 — Vitest for unit testing

**Date:** 2026-06-04  
**Status:** Accepted

## Decision

Use **Vitest** for unit tests. The methodology specifies Vitest (§2 table: "Vitest (unit)").
Test files are named by TC-ID from the FRD: `TC-070.1-rls-cross-tenant.test.ts`.
Playwright for E2E (tests/e2e/).
